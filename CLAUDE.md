# Claude repository guide

Follow [`AGENTS.md`](AGENTS.md) as the authoritative development guide for this
repository. The sole production package is `src/daita/`; tests live in `tests/`,
documentation in `docs/`, and examples in `examples/`.

Run commands from the repository root in a dedicated Python 3.11 or 3.12
environment. Do not recreate the removed root-level `daita/` package, isolated
replacement tree, or any superseded workflow/runtime architecture.
